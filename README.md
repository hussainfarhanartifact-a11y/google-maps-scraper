# 🗺️ Google Maps Business Scraper
By Hussain Farhan

Searches Google Maps for any keyword and location and scrapes business details. Exports to CSV.

## What it does
- Search any keyword + location (e.g. "dentists in Dubai")
- Extracts name, rating, reviews, address, phone, website
- Saves to google_maps_data.csv

## How to run
pip install selenium webdriver-manager
python google_maps_scraper.py

## Tech used
Python, Selenium, webdriver-manager
